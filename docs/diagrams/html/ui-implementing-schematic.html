Gate 1 · Code Eval

EVALUATE spawns an Opus sub-agent on impl-eval.md to check code against specs. FAIL < max drops to re-IMPLEMENT and re-evaluates; PASS (or force-accept at max) proceeds to QA. Counter: eval_round.

impl-eval.md · forgectl eval

Gate 2 · QA Placement

QA_TEST drives the live app through the Playwright MCP — placement, interaction, console. FAIL loops to UI_REFINE (move / resize / rewire — no commit). It always writes qa/batch-N-steps.json, the contract handed to e2e. Counter: qa_round.

ui-qa-eval.md · Playwright MCP

Gate 3 · E2E Verify

E2E_AUTHOR turns the step list into runnable Playwright tests, then E2E_VERIFY confirms they run, pass, and cover. FAIL loops to E2E_REMEDIATE; zero scenarios is a vacuous PASS. Counter: e2e_round → COMMIT.

ui-e2e-eval.md · Playwright runner
