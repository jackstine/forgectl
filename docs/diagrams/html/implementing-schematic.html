Batch loop

ORIENT → IMPLEMENT → EVALUATE. ORIENT selects up to batch unblocked items in layer order; IMPLEMENT writes complete code for each item in turn — no stubs — running tests as it goes, then hands the whole batch to EVALUATE.

forgectl advance · plan.json

Eval / refine

EVALUATE spawns an AI sub-agent that scores the batch across 7 dimensions and writes evals/batch-N-round-M.md. FAIL < max drops to re-IMPLEMENT and re-evaluates; PASS ≥ min (or force-accept at max) proceeds to COMMIT. Counter: rounds.

impl-eval.md · forgectl eval

Commit & shift

COMMIT is the batch boundary — passed and force-accepted items land together. More batches / layers loop back to ORIENT; when every layer is terminal, DONE hands off to PHASE_SHIFT, routed onward by plan queue and kind.
