Per-spec loop

ORIENT → SELECT → DRAFT → EVALUATE. An Opus sub-agent scores each spec against 11 dimensions. FAIL drops to REFINE and re-enters EVALUATE; PASS (≥ min_rounds) reaches ACCEPT. While the queue holds specs, ACCEPT loops back to ORIENT for the next one.

Reconciliation

When the queue empties, DONE hands off to RECONCILE — cross-validating dependencies, integration symmetry, and naming across all specs. RECONCILE_EVAL → RECONCILE_REVIEW gates the result; reject loops back, accept advances to COMPLETE.

One commit, one shift

COMPLETE is the single specifying commit — every accepted spec lands together. Then PHASE_SHIFT fires: a hard stop that refreshes context before generate_planning_queue (or a direct advance --from plan-queue.json).
