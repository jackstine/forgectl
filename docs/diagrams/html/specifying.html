Specifying

Permanent behavioral contracts. Each spec in the queue is oriented, drafted, and put through an adversarial 11-dimension evaluation loop by an AI sub-agent. Cross-spec reconciliation validates dependencies and symmetry before a single commit at COMPLETE.

Role Systems Architect Input spec-queue.json Output specs/*.md Eval 11-dimension review
Initialization
①
Command
forgectl init
flag--phase specifying
flag--from spec-queue.json
opt--guided

Bootstraps the specifying state machine. Config keys read from .forgectl/config: batch, eval.max_rounds, eval.min_rounds. Pass --guided to enable user checkpoints before each spec is drafted.

Produces
forgectl-state.json → queue loaded → ORIENT

Evaluation Loop — specifying.eval.min_rounds .. max_rounds
⑤
State
EVALUATE
Action: forgectl advance --verdict PASS|FAIL --eval-report <path>
out<domain>/specs/.eval/batch-N-rN.md

Spawn an Opus sub-agent to review the spec batch against 11 evaluation dimensions. Output is a structured eval report. Verdict drives the branch below.

Verdict branch
EVALUATE →
PASS ≥min_rounds → ACCEPT
FAIL <max_rounds → REFINE ⟲ EVALUATE
⑥
State · Loop
REFINE
Action: forgectl advance

Fix deficiencies identified in the eval report. Address all flagged dimensions before re-entering EVALUATE.

Loop-back
REFINE ⟲ EVALUATE

⑦
State · Terminal (per-spec)
ACCEPT
Action: forgectl advance

Spec finalized. No commit here — the single specifying commit occurs at COMPLETE. From here the queue branches.

Queue branch
more specs ⟲ ORIENT (next spec)
queue empty → DONE → reconciliation
Reconciliation — cross-spec consistency
⑧
State
RECONCILE
Action: forgectl advance

Cross-validate all specs across all domains: Depends On refs point to existing specs; Integration Points are symmetric; no circular cross-domain dependencies; naming consistency across all specs.

Transitions to
RECONCILE → RECONCILE_EVAL
⑨
State · Eval
RECONCILE_EVAL
Action: forgectl advance --verdict PASS|FAIL --eval-report <path>
configreconciliation.min_rounds (def: 0)
configreconciliation.max_rounds (def: 3)

Reconciliation evaluation bounded by specifying.reconciliation.min_rounds and specifying.reconciliation.max_rounds from config.

Verdict branch
RECONCILE_EVAL →
PASS → RECONCILE_REVIEW → accept → COMPLETE
FAIL → RECONCILE_REVIEW ⟲ RECONCILE (another pass)
⑩
State · Gate
RECONCILE_REVIEW

Human or agent review of reconciliation results. On accept → COMPLETE. On reject → loop back to RECONCILE for another pass.

Outcome
accept → COMPLETE
reject ⟲ RECONCILE
✓
State · Terminal
COMPLETE
Action: forgectl advance [--message <msg>]
outgit commit (specs)

The single specifying commit — all accepted specs committed together. --message required when enable_commits: true in config. Phase ends; PHASE_SHIFT fires.

Terminal
COMPLETE → PHASE_SHIFT
PHASE_SHIFT → generate_planning_queue — or advance --from plan-queue.json → Planning directly
