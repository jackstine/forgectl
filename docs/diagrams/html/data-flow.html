Implements each batch item, evaluates against impl-eval.md, and commits. FAIL re-enters implement at round 2+; more batches loop back until the queue drains. plan.json items are mutated with passes: "passed" | "failed" and an incremented rounds count.

Reuses the implementing spine, then inserts two extra verification loops between code eval and commit. A passed item means all three loops passed within budget; failed means at least one loop was forced. rounds counts eval + QA + e2e rounds combined. Authored *.spec.ts files are permanent assets written to the project's e2e test directory.

CODE EVAL→ QA ⟲ UI_REFINE→ E2E ⟲ E2E_REMEDIATE→ COMMIT

plan.json

Lives at <domain>/.forge_workspace/implementation_plan/plan.json. Produced by Planning; mutated by PHASE_SHIFT (adds passes and rounds to every item) and updated throughout implementation as items complete.

{
  "context": { "domain": "api", "module": "github.com/org/api" },

  "refs": [{ "id": "notes-config", "path": "notes/config.md" }],

  "layers": [
    { "id": "L0", "name": "Foundation", "items": ["config.types"] },
    { "id": "L1", "name": "Core Logic", "items": ["auth.middleware"] }
  ],

  "items": [{
    "id": "config.types", "name": "Configuration types",
    "description": "Go structs for service config",
    "depends_on": [], "steps": ["Create types.go"],
    "files": ["internal/config/types.go"],
    "specs": ["service-configuration.md"],
    "refs": ["notes/config.md"],
    "tests": [{ "category": "functional", "description": "loads valid" }],
    "passes": "pending", // added by PHASE_SHIFT → "passed" | "failed"
    "rounds": 0 // incremented each eval
  }]
}
Path Resolution Rules
Path Resolution

Paths in plan.json are resolved relative to different roots. The validation gate resolves all paths before allowing EVALUATE — refs[].path and items[].refs must point to existing files on disk.

Field Resolved relative to
refs[].path plan.json directory (<domain>/<ws>/implementation_plan/)
items[].refs (notes files) plan.json directory
items[].specs (spec files) project root
items[].files (source files) project root
