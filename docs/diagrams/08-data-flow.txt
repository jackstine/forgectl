  STATE FILE: .forgectl/state/forgectl-state.json
  ═══════════════════════════════════════════════════════════════════════════

  Persistent across all phases. Written atomically (tmpfile → backup → rename).
  Config nested under "config" object mirroring TOML structure.

  ═══════════════════════════════════════════════════════════════════════════
  PATH RESOLUTION RULES
  ═══════════════════════════════════════════════════════════════════════════

  Paths in plan.json are resolved relative to different roots:

  ┌─────────────────────────────┬────────────────────────────────────────┐
  │ Field                       │ Resolved relative to                   │
  ├─────────────────────────────┼────────────────────────────────────────┤
  │ refs[].path                 │ plan.json directory                    │
  │                             │ (<domain>/<ws>/implementation_plan/)   │
  │ items[].refs (notes files)  │ plan.json directory                    │
  │ items[].specs (spec files)  │ project root                           │
  │ items[].files (source files)│ project root                           │
  └─────────────────────────────┴────────────────────────────────────────┘

  The validation gate resolves all paths before allowing EVALUATE.
  refs[].path and items[].refs must point to existing files on disk.
